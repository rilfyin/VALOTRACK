新しい版を出す

  1. 新しい VALOTRACK-Setup.exe をこのフォルダに上書きで置く
  2. 下でバージョンと変更点を入れて、出てきた JSON を manifest.json に貼る
  3. 以上。利用者のアプリは起動6秒後に気づきます
{}
バージョンは必ず上げてください。 同じか小さい番号だと «更新あり» になりません。 比較は数字ごとなので 2.10.0 は 2.9.0 より新しい扱いです。

サーバーへの置き方

あなたのドメイン/valotrack/
  ├─ manifest.json          ← 認証なしで読めるようにする（必須）
  ├─ VALOTRACK-Setup.exe    ← 同上
  ├─ index.html             ← このページ。自分だけが見られるようにする
  ├─ .htaccess              ← 上2つは公開、このページだけ保護
  └─ robots.txt             ← 検索に載せない
manifest.json と exe はログイン不要にしてください。 利用者のアプリはログインできないため、保護すると更新に気づけません。 URL を人に教えず、検索避けをしておけば実質見られません。

このページだけに鍵をかける（Apache）

.htaccess をこのフォルダに置きます。ユーザー名とパスワードは htpasswd -c /パス/.htpasswd 好きな名前 で作ります。 

# このフォルダは既定で要認証
AuthType Basic
AuthName "VALOTRACK"
AuthUserFile /絶対パス/.htpasswd
Require valid-user

# ただし更新に必要な2つだけは誰でも読める
<FilesMatch "^(manifest\.json|VALOTRACK-Setup\.exe)$">
  Require all granted
</FilesMatch>

Nginx なら location = /valotrack/index.html { auth_basic "VALOTRACK"; auth_basic_user_file …; } で同じことができます。
